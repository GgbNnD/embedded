# 数据集标注说明

本文档说明如何为 YOLO 物资检测项目采集并标注数据，默认工具为 `labelImg`，标注格式为 YOLO。

## 1. 类别清单

第一版固定类别以 [configs/classes.yaml](/home/cells/embedded/configs/classes.yaml) 为准。当前模板包括：

- `cboard`
- `dmj4310`
- `m3508`

当前项目的类别顺序必须和 `labelImg` 使用的 `classes.txt` 完全一致。对 YOLO 来说，标签文件里保存的是数字 id，所以顺序不一致会直接导致类别学反。

## 2. 数据采集要求

每个类别都应尽量覆盖以下情况：

- 单个目标
- 多个同类目标
- 多类混放
- 有轻微遮挡
- 不同距离和角度
- 不同背景和光照

建议：

- 图片清晰，不要大面积拖影
- 尽量避免只拍“最标准角度”
- 同一批次里保留一部分困难图片，用于后续提升鲁棒性

## 3. 启动标注工具

如果 `labelImg` 已安装，可在 `alg` 环境中启动：

```bash
conda run -n alg labelImg
```

启动后建议设置：

- Open Dir：选择图片目录
- Change Save Dir：选择标签保存目录
- Save Format：YOLO
- Predefined Classes：使用统一类别列表

如果你想避免手动重复输入类别名，可以先把 `configs/classes.yaml` 中的类别整理好，再手动同步到 `labelImg` 的类别配置中。

## 4. 框选规则

- 每个独立物资画一个矩形框
- 框尽量贴近目标边缘，但不要切掉主体
- 不要把多个独立目标画进同一个框
- 不要给同一目标重复画多个框
- 遮挡但仍然可以明确识别类别的目标要标注
- 无法确认类别的目标不要硬标

## 5. 常见错误

- 框太大，把大量背景也包含进去
- 框太小，切掉了物资主体
- 同一类使用多个名字，例如 `M3508` 和 `m3508`
- 漏掉图片边缘的小目标
- 多个目标粘连时只标了一个框
- 标签文件与图片文件名不对应

## 6. 质检建议

每次标注完一批数据后，至少做一次抽检：

- 随机抽 20 张图检查
- 检查类别名是否统一
- 检查标签 id 是否和类别顺序一致
- 检查是否有空标签、重复标签、错位标签
- 检查 train/val/test 是否按图片而不是按标签分目录

如果模型首轮训练后某一类表现明显不好，先回看该类样本：

- 是否数量过少
- 是否只有单一角度
- 是否存在大量模糊或反光
- 是否有系统性错标或漏标

## 7. 数据集目录规范

```text
datasets/materials/
├── images/
│   ├── train/
│   ├── val/
│   └── test/
└── labels/
    ├── train/
    ├── val/
    └── test/
```

图片与标签要求同名，例如：

- `images/train/img_001.jpg`
- `labels/train/img_001.txt`

每个 YOLO 标签文件每一行格式为：

```text
class_id x_center y_center width height
```

其中坐标都是归一化到 `0~1` 的浮点数。
