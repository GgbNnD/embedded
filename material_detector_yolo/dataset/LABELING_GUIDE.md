# YOLO 多物资标注指南（中文示例版）

## 先回答你的问题

是的，要同时标注。

如果一张图里同时出现 `C620` 和 `DM-J4310`，你需要在同一张图的标签文件里分别写两行（每个目标一行）。

---

## 1. 类别先定义好

先在 `material_detector_yolo/configs/classes.txt` 定义类别顺序，例如：

```text
c620
dm_j4310
m3508
```

对应关系就是：
- `c620` -> class_id `0`
- `dm_j4310` -> class_id `1`
- `m3508` -> class_id `2`

建议类别名用小写英文/下划线（如 `dm_j4310`），避免空格和特殊字符带来兼容问题。

---

## 2. YOLO 标签格式

每个目标一行，格式固定：

```text
<class_id> <x_center> <y_center> <width> <height>
```

注意：
- 坐标都要归一化到 `0~1`
- 不是像素值
- 一张图有几个目标，就有几行

---

## 3. 你这个场景的直接示例

假设图片是 `images/train/frame_0001.jpg`，里面有 1 个 C620 + 1 个 DM-J4310。

对应标签文件：`labels/train/frame_0001.txt`

```text
0 0.260000 0.520000 0.190000 0.260000
1 0.710000 0.500000 0.240000 0.320000
```

解释：
- 第一行是 C620（class 0）
- 第二行是 DM-J4310（class 1）

---

## 4. 不同情况示例

## 示例 A：同类多个 + 异类一个

图中：3 个 C620 + 1 个 DM-J4310

```text
0 0.150000 0.530000 0.120000 0.180000
0 0.330000 0.500000 0.130000 0.170000
0 0.520000 0.550000 0.140000 0.190000
1 0.780000 0.510000 0.220000 0.300000
```

要点：同类有几个就写几行，不是只写一行。

## 示例 B：只有一个目标

图中：仅 1 个 DM-J4310

```text
1 0.460000 0.520000 0.280000 0.360000
```

## 示例 C：无目标（负样本）

图中：没有你关心的物资类别。

做法：保留同名空标签文件（0 字节即可）。

例如：
- `images/train/frame_0100.jpg`
- `labels/train/frame_0100.txt`（空文件）

这类样本对降低误检很有帮助。

## 示例 D：部分遮挡

图中：DM-J4310 被遮挡了一部分，但还能辨认。

做法：仍然标注，框紧贴可见区域主体，不要把大量不可见区域猜进去。

## 示例 E：目标在画面边缘

图中：C620 只有一半出现在画面中。

做法：如果可见部分足够识别（建议可见 >= 30%），仍标注；
如果只露出很小碎片、连人都难判断类别，可以不标。

---

## 5. 像素框转 YOLO 的计算示例

若图片尺寸是 `1280x720`，目标框像素坐标为：
- `x_min=100, y_min=200, x_max=356, y_max=500`
- 类别为 `c620`（class_id=0）

计算：
- `x_center = ((100+356)/2)/1280 = 0.178125`
- `y_center = ((200+500)/2)/720 = 0.486111`
- `width = (356-100)/1280 = 0.200000`
- `height = (500-200)/720 = 0.416667`

标签行：

```text
0 0.178125 0.486111 0.200000 0.416667
```

---

## 6. 标注一致性规则（非常重要）

- 同一类物资始终用同一个 class_id
- 框尽量贴紧目标外轮廓（不要过大）
- 不要漏标（漏标会被模型当背景）
- 不要错标（错标会直接污染模型）
- 训练/验证/测试按场景拆分，避免同一场景同时出现在 train 和 test

---

## 7. 常见错误

- 把像素值直接写进 YOLO txt（错误）
- 一张图只写“类别存在”，不写每个实例（错误）
- 图中有目标但标签文件为空（严重错误）
- 类别顺序改了但旧标签没同步（严重错误）

---

## 8. 你可以直接照这个最小流程做

1. 先确定类别清单（`classes.txt`）
2. 用 LabelImg/CVAT 逐图画框
3. 导出 YOLO 格式标签
4. 抽查 50 张，重点看“漏标/错标/空标签错误”
5. 再开始训练
